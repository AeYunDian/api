# Varlet（Vue 3）组件文档

> 依据 Varlet 官方中文文档整理｜数据来源：仓库 `varletjs/varlet` 的 `dev` 分支（`packages/varlet-ui/src/<组件>/docs/zh-CN.md`）｜覆盖官方文档站全部 **78 个组件 / 指令**，每个组件一个独立文件。

## 阅读方式

- **一个组件一个文件**：文件名是组件的 kebab-case 英文名，例如按钮是 [基础组件/button.md](基础组件/button.md)、日期选择器是 [反馈组件/date-picker.md](反馈组件/date-picker.md)。
- 每个文件开头有一行元信息：分类、组件标签（如 `<var-button>`）、官方文档链接、返回本索引。
- 文件内部统一按 **用途 → 基础用法 → Props → Events → Slots → Methods → 注意** 排列；`Props` 表完整保留官方属性（含 `3.18.0` 这类版本标注、`_string | number_` 类型与默认值）。
- 部分组件有配套的子组件 / 数据类型，收在同一个文件里作为二级小节，例如：
  - `基础组件/button.md` 含 `ButtonGroup`（`<var-button-group>`）
  - `表单组件/uploader.md` 含 `VarFile`、`VarFileUtils`
  - `导航组件/tree-menu.md` 含 `TreeMenuOption`
  - `表单组件/form.md` 含 `FormItem`（官方并无独立 form-item 组件，文件内已据实说明）

## 安装

```bash
npm i @varlet/ui -S
# 或
pnpm add @varlet/ui
```

## 全量引入

```js
import { createApp } from 'vue'
import App from './App.vue'
import Varlet from '@varlet/ui'
import '@varlet/ui/es/style'

createApp(App).use(Varlet).mount('#app')
```

## 按需引入（推荐）

```js
import { Button, Snackbar, Dialog } from '@varlet/ui'
```

配合 `@varlet/import-resolver` + `unplugin-vue-components` 可自动按需引入组件与样式：

```js
// vite.config.js
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { VarletImportResolver } from '@varlet/import-resolver'
import Components from 'unplugin-vue-components/vite'

export default defineConfig({
  plugins: [
    vue(),
    Components({ resolvers: [VarletImportResolver()] }),
  ],
})
```
