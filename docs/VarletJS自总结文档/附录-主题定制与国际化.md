## CSS 变量与主题定制

组件样式全部由 CSS 变量组织，命名形如 `--组件-语义-用途`，例如 `--button-primary-color` 即按钮主色。官方文档中每个组件末尾的「样式变量」表列出了该组件可覆盖的全部变量（每个组件几十条，数量庞大，本文档未逐个罗列）；实际项目中通常只覆盖少量语义变量（如 `--color-primary`、`--font-size-md`）即可完成主题定制，需要精细控制时再按官方变量名逐个覆盖。

```css
:root {
  --color-primary: #00b96b;
  --button-primary-color: var(--color-primary);
}
```

局部覆盖用 `StyleProvider`（标签 `var-style-provider`），`style-vars` 传入变量对象，只作用于其包裹的子树：

```html
<var-style-provider :style-vars="{ '--button-primary-color': 'var(--color-success)' }">
  <var-button type="primary">局部主题按钮</var-button>
</var-style-provider>
```

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `style-vars` | CSS 变量 | _Record<string, string>_ | `{}` |
| `tag` | 自定义标签名 | _string_ | `div` |

- `style-vars` 的键名必须是完整变量名（含 `--` 前缀），值为合法 CSS 值或 `var()` 引用。
- 把它绑定到 `ref(null)` 与主题对象之间切换，即可动态开关局部样式；传 `null` 表示不覆盖。
- 组件本身没有 `scope` 参数，作用范围由组件包裹的 DOM 子树界定；`teleport` 到 `StyleProvider` 之外的弹层不会继承这些变量，这类场景应改用全局 `:root` 覆盖。

## 暗色模式与内置主题

暗色模式通过在 `html`（`documentElement`）上增删主题类开启，无需重新引入样式：

```js
// 强制暗色
document.documentElement.classList.add('var-theme-dark')
// 亮暗跟随系统（prefers-color-scheme）
document.documentElement.classList.add('var-theme-dark-system')
// 恢复亮色：移除对应主题类
document.documentElement.classList.remove('var-theme-dark', 'var-theme-dark-system')
```

| 主题 | 启用方式 | 说明 |
| --- | --- | --- |
| Material Design 2 亮色 | 默认 | 不加任何主题类 |
| Material Design 2 暗色 | `var-theme-dark` | 强制暗色，忽略系统偏好 |
| 跟随系统 | `var-theme-dark-system` | 由 `prefers-color-scheme` 决定亮 / 暗 |
| Material Design 3 亮色 / 暗色 | `Themes.md3Light` / `Themes.md3Dark` | 以主题对象覆盖全局变量 |

其它内置主题以变量对象形式导出，可用函数式 `StyleProvider` 一次性写入 `:root`，传 `null` 恢复默认亮色：

```js
import { StyleProvider, Themes } from '@varlet/ui'

StyleProvider(Themes.dark)      // Material Design 2 暗色
StyleProvider(Themes.md3Light)  // Material Design 3 亮色
StyleProvider(Themes.md3Dark)   // Material Design 3 暗色
StyleProvider(null)             // 恢复默认亮色
```

切换主题后建议让页面底色与文字跟随变量：给 `body` 设置 `background-color: var(--color-body)`、`color: var(--color-text)`。自定义主题推荐基于内置主题对象扩展，只覆盖需要修改的变量，如 `StyleProvider({ ...Themes.md3Light, '--color-primary': 'red' })`。

## 国际化

组件库默认中文，语言包以 `Locale.语言编码` 形式导出（如 `Locale.zhCN`、`Locale.enUS`）。常用 API：

| API | 说明 |
| --- | --- |
| `Locale.add(name, messages)` | 注册（扩展）语言包 |
| `Locale.merge(name, messages)` | 覆盖已注册语言包中的部分文案 |
| `Locale.use(name)` | 切换当前语言（操作单例实例） |

```js
import { Locale } from '@varlet/ui'

Locale.add('en-US', Locale.enUS)                  // 注册语言包
Locale.merge('en-US', { dialogTitle: 'Hello' })   // 覆盖个别文案
Locale.use('en-US')                               // 切换语言
```

需要与响应式数据联动时用 `LocaleProvider`（标签 `var-locale-provider`）声明式切换，属性 `locale`（_string_，默认 `zh-CN`）、`messages`（_Record<string, Record<string, string>>_）、`tag`（_string_，默认 `div`）：

```vue
<template>
  <var-locale-provider :locale="locale" :messages="messages">
    <var-date-picker v-model="date" />
    <var-button @click="locale = locale === 'zh-CN' ? 'en-US' : 'zh-CN'">切换语言</var-button>
  </var-locale-provider>
</template>
```

内置语言包（编码 / 导出名 / 支持版本）：`zh-CN` — _Locale.zhCN_（`v2.0.0`）、`en-US` — _Locale.enUS_（`v2.0.0`）、`zh-TW` — _Locale.zhTW_（`v2.17.0`）、`zh-HK` — _Locale.zhHK_（`v2.17.0`）、`fa-IR` — _Locale.faIR_（`v2.22.0`）、`ja-JP` — _Locale.jaJP_（`v3.9.0`）。

- 组件内使用：切换语言后，`DatePicker`、`Pagination`、`Dialog` 等组件的内置文案自动跟随当前语言包，业务代码只需负责切换语言。
- `Locale.use` 操作的是单例语言实例，服务端渲染场景不要使用；该场景应改用 `LocaleProvider`，它只对包裹的子孙组件生效，且对组件的函数式调用无效。
