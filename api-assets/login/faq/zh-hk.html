常見問題

1. 什麼是 AyAccount？

AyAccount 是登入韻典旗下軟件的憑證，即 AY 帳號。

您可透過在韻典旗下軟件登入方式中選擇 AyAccount，快速建立 AY 帳號，並成功登入。

用戶電郵是 AY 帳號的唯一 ID，您可登入 AY 帳號官網查看該帳號的電郵。

2. 無法登入 AY 帳號？

情境一：忘記密碼

您可以在登入頁點擊「忘記密碼」，驗證身份後即可重新設定新的登入密碼。

情境二：身份驗證

系統偵測到您的帳號存在風險，為保障您的帳號安全，請您根據提示內容完成驗證，驗證成功後即可登入。

情境三：電郵停用

若帳號綁定的電郵無法正常接收郵件，您可透過這些聯絡方式聯絡我們，通過驗證後，即可更改綁定電郵。

換綁成功後即可使用新電郵登入。

3. 如何保護帳號安全？

1）請您填寫真實的資料，可作為判斷帳號所屬的重要憑證；

2）開啟新裝置驗證，當帳號在新裝置上使用密碼登入客戶端應用時需要通過驗證；

3）綁定電郵，可以用作找回帳號的身份驗證方式；

4）若帳號綁定的電郵被他人修改，您可在登入AY 帳號（online.undz.cn） 後操作登入限制，解除限制前任何人將無法使用該帳號；

5）良好的安全意識能從源頭減少帳號歸屬糾紛，請妥善保管您的帳號避免他人使用。

4. 帳號被盜如何找回？

1）若您的帳號密碼洩露，您可透過綁定電郵驗證身份，重新設定密碼；

2）若帳號綁定的電郵被他人修改，正常流程無法找回，用戶可透過 這些聯絡方式 聯絡我們驗證，驗證通過後修改綁定的電郵；

3）若您的帳號正被他人使用，您可在登入 AY 帳號（online.undz.cn） 後操作「登入限制」，解除限制前任何人將無法使用該帳號。

其他問題

1. 登入時為什麼需要安全驗證？

1）系統偵測到您的帳號存在風險，為保障您的帳號安全，請您根據提示內容完成身份驗證；

2） AY 帳號（online.undz.cn） 內若開啟新裝置驗證，帳號在新裝置上登入遊戲時需要驗證。

2. 什麼是新裝置驗證？

新裝置驗證是為 AY 帳號（online.undz.cn） 提供的一層安全保護。在新裝置上登入時將驗證您的綁定電郵，否則不能登入。新裝置驗證預設為關閉。

若以上未能解決您的問題，請透過 aeyundian@outlook.com 或 這些聯絡方式 聯絡我們。
